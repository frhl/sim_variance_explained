# 🧬 Interactive Genetic Architecture Explorer

A web-based tool for visualizing additive vs. non-additive genetic effects.

## 🌐 [Live Demo](https://frhl.github.io/sim_variance_explained)

Companion tool for the research paper "Deviations from genetic additivity driven by rare variants at biobank scale" by Lassen et al.

## Features
- Interactive visualization of genetic architectures
- HWE testing and custom genotype counts
- Preset buttons for common inheritance patterns
- Professional, responsive design
